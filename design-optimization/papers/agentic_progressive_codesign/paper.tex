\begin{abstract}
A software optimization can become worthwhile only after the hardware changes. Larger tiles need sufficient registers, fusion changes storage lifetimes, and reuse depends on the memory system's ability to serve concurrent work. Designing AI infrastructure therefore requires choosing algorithms, programs, interfaces, and hardware together. It also requires a representation that makes useful combinations available to the optimizer. We develop Agentic Progressive Co-Design around an evolving mixed-integer program (MIP). Agents enrich coarse computation graphs with tensor dependencies and implementation alternatives, introduce software--hardware boundary choices, and restructure the resulting formulation to make coupled search tractable. One assignment specifies both a program and its matching hardware configuration; execution feedback guides which alternatives to retain and which model assumptions to revise. Streaming attention and programmable transfer mechanisms illustrate how the formulation connects algorithmic choices to hardware cost and capability. Preliminary experiments achieve a $7.02\times$ aggregate speedup on a programmable architecture benchmark and $2.93\times$ prefill and $3.58\times$ decode speedups on the open-source Ventus GPU architecture. Controlled comparisons show gains from optimizing either software or hardware, with larger gains when both can change. Hardware changes make previously unfavorable tiling and attention mappings useful, while model revisions expose additional beneficial combinations. These results motivate a design process that revisits earlier choices as its representation becomes more expressive, while allocating search effort to the interactions that determine implementation quality.
\end{abstract}
