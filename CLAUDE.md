# Instructions for Claude Code in this repository

## Writing style

Write the way you'd talk to a computer architect at a whiteboard. Short sentences. Concrete nouns: queue, pipe, cycle, bank. No abstractions like 'exercised', 'faithful', 'inventory', 'trajectory'. If a sentence needs a second read, rewrite it. Say the number, then the cause, then the fix.

This applies to reports to Li, commit messages, gap-log entries and design-note revisions.
