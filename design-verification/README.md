# Design Verification

This area studies whether the structures introduced during progressive hardware–software co-design preserve the workload computation.

The current [paper](papers/agentic_progressive_verification/paper.tex) develops backward abstraction maps, local preservation obligations, composition, and incremental reuse. Its evaluation uses bounded models; it does not claim a fully verified generated implementation or autonomous proof construction.

Compile the standalone LaTeX source with a LaTeX installation providing TikZ and the standard packages listed in its preamble. Run the compiler twice to resolve references.
